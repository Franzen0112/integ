# JJRK Studio

Photography & videography booking site (static HTML + Supabase).

## Quick start (local)

```powershell
node scripts/extract-images.js
npm start
```

Open http://127.0.0.1:8080/dashboard.html

## Supabase SQL (run in order)

1. `supabase-schema.sql`
2. `fix-rls-policies.sql`
3. `messaging-schema.sql` + `fix-messaging-rls.sql` (contact / admin inbox)
4. `images-schema-vercel.sql` (photos + Storage)
